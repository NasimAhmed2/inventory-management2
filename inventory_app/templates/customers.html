Excel File Instructions

The first row must contain all 11 column headers. Header capitalization and surrounding spaces are ignored.

Type Name Mobile Email VAT Number Address Payment Type Credit Limit
consumer Rahul Sharma 9876543210 rahul@example.com VAT12345 Delhi, India cash 0
retailer ABC Computers 9876501234 Noida, Uttar Pradesh credit 25000
  • All 8 column headers shown above are required, even if some values are optional.
  • Type must be consumer, retailer, or wholesaler.
  • Name cannot be blank.
  • Mobile, Email, VAT Number, and Address may be blank.
  • Payment Type must be cash or credit. A blank value defaults to cash.
  • Credit Limit defaults to 0 and cannot be negative.
  • Format Mobile cells as Text to preserve leading zeros and long numbers.
  • Customer Code is generated automatically and should not be included.
