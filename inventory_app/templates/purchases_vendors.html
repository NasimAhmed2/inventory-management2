Excel File Instructions

The first row must contain all 9 column headers. Header capitalization and surrounding spaces can be ignored by the import view if it supports header normalization.

Name PAN VAT Number Mobile Email Address Opening Balance Opening Balance Type
ABC Computers ABCDE1234F VAT12345 9876543210 abc@example.com Delhi, India 25000 DR
XYZ Electronics 9876501234 Noida, Uttar Pradesh 10000 CR
  • All 9 column headers are required in the sample format.
  • Name is required. Other fields may be left blank if your import view permits it.
  • Vendor Code should be unique. If your application generates vendor codes automatically, leave this column blank and let the import view generate them.
  • Opening Balance must be a number and cannot be negative if your import logic validates it as a positive amount.
  • Opening Balance Type must be DR or CR. DR means you owe the vendor; CR means the vendor owes you.
  • Format Mobile cells as Text to preserve leading zeros.
  • Supported formats: .xlsx and .xls. Maximum size: 5 MB.
